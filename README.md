# **KASHISH PORTFOLIO**

A modern, responsive personal portfolio built with **React.js** and deployed on **Netlify**. This project showcases my frontend development skills, professional experience, and creative projects.

## **✨ KEY FEATURES**
- **Component-Based Architecture**: Modular and reusable React components.
- **Smooth Scrolling**: Seamless navigation between different page sections.
- **Fully Responsive**: Optimized for all screen sizes from mobile to 4K monitors.
- **Project Showcases**: Interactive cards featuring my web apps and the Mount & Blade: Warband historical mod.
- **Optimized Performance**: Fast load times and clean code structure.

## **🛠️ TECHNOLOGIES USED**
- **Core**: React.js (Hooks, Functional Components)
- **Build Tool**: Vite
- **Styling**: CSS3 / Responsive Design
- **Icons**: Lucide React
- **Deployment**: Netlify (Continuous Deployment)
- **Version Control**: Git & GitHub
